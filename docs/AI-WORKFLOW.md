# AI Workflow
 
## Цель
 
Сделать работу Claude Code экономичной, безопасной и предсказуемой.
 
## Основные правила
 
1. Маленькие задачи.
2. Сначала план.
3. Потом точечное изменение.
4. Проверка после изменения.
5. Не переписывать весь проект.
6. Не добавлять зависимости без необходимости.
7. Не менять API без обновления документации.
8. Не менять SQL без обновления `schema.sql`.
 
## Хорошие запросы
 
```text
Используй project-planner. Посмотри проект и предложи маленький план улучшения. Код пока не меняй.
```
 
```text
Используй safe-change. Добавь секцию популярных задач на frontend. Не меняй общий стиль.
```
 
```text
Используй backend-api. Добавь endpoint для получения статистики задач.
```
 
```text
Используй sql-change. Добавь таблицу topics и обнови seed.sql.
```
 
```text
Используй qa-reviewer. Проверь проект после изменений.
```
 
## Плохие запросы
 
```text
Сделай весь сайт полностью.
```
 
```text
Переделай всё красиво.
```
 
```text
Добавь всё, что нужно.
```
 
Такие запросы дорогие, неопределённые и чаще ломают проект.
 
## Правильный цикл
 
1. План.
2. Маленькая правка.
3. Проверка.
4. Отчёт.
5. Следующая правка.
