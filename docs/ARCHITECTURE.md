# Архитектура Python Code Arena
 
## Назначение
 
Python Code Arena — учебная платформа для изучения Python и решения задач из собеседований.
 
## Части проекта
 
### Frontend
 
Папка:
 
```text
frontend/
```
 
Назначение:
 
- показать главную страницу;
- показать список задач;
- открыть задачу;
- принять код пользователя;
- отправить код на backend;
- показать результат проверки.
 
Технологии:
 
- HTML
- CSS
- JavaScript
 
### Backend
 
Папка:
 
```text
backend/
```
 
Назначение:
 
- хранить задачи в SQLite;
- отдавать задачи через API;
- принимать решения;
- проверять решения тестами;
- сохранять попытки в таблицу submissions.
 
Технологии:
 
- Python
- Flask
- SQLite
 
### Database
 
Папка:
 
```text
backend/sql/
```
 
Файлы:
 
- `schema.sql` — структура базы данных;
- `seed.sql` — стартовые данные.
 
## Главный user flow
 
1. Пользователь открывает frontend.
2. Frontend запрашивает `/api/tasks`.
3. Пользователь выбирает задачу.
4. Frontend запрашивает `/api/tasks/<slug>`.
5. Пользователь пишет функцию `solve`.
6. Frontend отправляет код на `/api/check`.
7. Backend запускает тесты.
8. Backend возвращает результат.
9. Frontend показывает результат.
 
## Почему пока без React
 
На MVP важнее:
 
- простота;
- понятность;
- меньше зависимостей;
- дешевле работа с Claude Code;
- проще отладка для учебного проекта.
 
React можно добавить позже, когда появятся:
 
- много страниц;
- сложное состояние;
- авторизация;
- профиль;
- прогресс;
- полноценный кабинет ученика.
 
## Важное ограничение
 
Запуск кода пользователя — опасная операция. Текущая реализация подходит только для локального учебного MVP.
