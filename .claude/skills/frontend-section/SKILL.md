# Frontend Section Workflow
 
Use for UI sections in frontend/.
 
## Style
 
Python Code Arena should feel like:
- dark coding arena;
- Python learning platform;
- neon purple accents;
- clean cards;
- readable hierarchy.
 
## Before editing
 
Check:
1. Existing HTML structure.
2. Existing CSS variables.
3. Existing class naming.
4. Mobile layout.
 
## Rules
 
- Reuse components.
- Avoid duplicate CSS.
- Keep HTML semantic.
- Do not break existing IDs used by JavaScript.
- Do not change backend.
